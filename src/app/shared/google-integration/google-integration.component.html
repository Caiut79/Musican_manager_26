Come configurare Google Calendar (5 passaggi)

  1. Apri la Google Cloud Console e crea un nuovo progetto (es. "Musican Manager").
  2. Vai in API e Servizi → Libreria, cerca "Google Calendar API" e clicca Abilita.
  3. Vai in API e Servizi → Schermata consenso OAuth: seleziona "Esterno" e completa la procedura. Nella sezione Ambiti aggiungi https://www.googleapis.com/auth/calendar (permesso completo che include lista calendari e eventi CRUD). Nella sezione Utenti di prova aggiungi la tua email Google.
  4. Vai in API e Servizi → Credenziali → Crea credenziali → ID client OAuth 2.0: come Tipo applicazione scegli "Applicazione Web". In Autorizza origini JavaScript inserisci http://localhost:4200 e l'URL di produzione.
  5. Copia l'ID client (formato 12345-abc.apps.googleusercontent.com) e incollalo nella casella sottostante, poi clicca Salva. Non serve più modificare file.

Inserisci l'ID client creato dalla Google Cloud Console. Le impostazioni vengono salvate direttamente nel browser (nessun file da modificare).
